# NKOM Visual Design System
## The 7 Aberkane Principles as Marketing & In-App Assets

**Status:** Design Specification for Creative Team
**Version:** 1.0
**Purpose:** Guide designers in creating beautiful, scientifically-grounded visual assets
**Audience:** Graphic Designers, UX/UI Designers, Marketing Team

---

## DESIGN PHILOSOPHY

### Core Principle: "African Wisdom Meets Modern Science"

Every visual should communicate:
1. **Scientific credibility** (grounded in neuroscience)
2. **African heritage** (cultural authenticity, not appropriation)
3. **Accessibility** (simple enough for any audience)
4. **Hope & Empowerment** (students can succeed)
5. **Beauty** (designs should be enjoyed, not just consumed)

### Visual Language
- **African elements:** Geometric patterns, earth tones, natural forms
- **Modern elements:** Clean typography, smooth curves, 3D depth
- **Color palette:** NKOM brand colors (deep blue, terracotta, gold, warm gray)
- **Typography:** Montserrat (headings) + Inter (body)
- **Metaphors:** Journey, growth, light, connection

---

## DESIGN SYSTEM CONSTANTS

### Color Palette

**Primary Colors:**
```
Deep Blue:       #1E3A5F  (trust, science, stability)
Terracotta:      #C75B39  (African roots, warmth, energy)
Gold:            #D4AF37  (achievement, premium, wisdom)
Warm Gray:       #F5F5F0  (backgrounds, accessibility)
Charcoal:        #2C2C2C  (text, contrast)
```

**Accent Colors (for principles):**
```
Growth Green:    #4CAF50  (learning progress)
Curiosity Orange: #FF9800  (wonder, exploration)
Memory Purple:   #9C27B0  (retention, depth)
Connection Pink: #E91E63  (community, relationships)
Energy Yellow:   #FFC107  (joy, excitement)
Wisdom Bronze:   #795548  (legacy, knowledge)
Future Cyan:     #00BCD4  (innovation, forward)
```

### Typography

**Headings:** Montserrat Bold
- Principle names: 36px
- Subheadings: 24px
- Labels: 16px

**Body:** Inter Regular
- Descriptions: 14px
- Captions: 12px

**Accent:** Occasionally use African-inspired display font (1 word max)

### Layout Principles
- **Symmetry + Asymmetry:** Balanced but dynamic
- **Whitespace:** Generous margins, breathing room
- **Grid:** 4-column or 8-column, never cramped
- **Aspect ratios:**
  - Social tiles: 1:1 (Instagram), 16:9 (TikTok), 1200x628 (LinkedIn)
  - Website cards: 3-column grid (desktop), single-column (mobile)
  - In-app: Responsive, thumb-friendly

## THE 7 PRINCIPLES: DETAILED VISUAL SPECIFICATIONS

### PRINCIPLE 1: NEUROERGONOMICS
**Tagline:** "Work With Your Brain, Not Against It"

**Scientific Foundation:**
- Principle: System conforms to how brain naturally learns
- Reference: "L'art de bien utiliser le cerveau" (The art of using your brain well)

**Visual Metaphor:**
- A **key fitting into a lock** — custom fit, not forced
- OR: A **river flowing naturally** (not dammed up) — aligned with brain's natural state

**Design Direction:**

**Card Layout:**
```
┌─────────────────────────────────┐
│                                 │
│     [Key Illustration]          │
│     Perfect Fit                 │
│                                 │
│  Your Brain Knows How to Learn. │
│  NKOM Just Helps It Do Better.  │
│                                 │
│  ✓ Content Adapts to You        │
│  ✓ Not One-Size-Fits-All        │
│  ✓ Works With Your Brain        │
│                                 │
└─────────────────────────────────┘
```

**Visual Elements:**
- **Illustration:** Hand holding a custom key, multiple locks in background showing uniqueness
- **Colors:** Deep Blue (#1E3A5F) + Gold (#D4AF37) for highlight
- **Style:** Geometric, clean lines, slight 3D effect
- **Icons:** Matching key icon, brain outline (subtle)
- **Metaphor depth:** Key = personalization, lock = your unique brain

**Use Cases:**
- Website hero section
- In-app onboarding slide
- Instagram Reel intro (3 seconds)
- LinkedIn feature post

**Copy That Works With This Visual:**
> "One size doesn't fit all brains. NKOM's AI learns how YOUR brain learns. Personalization isn't a feature—it's the whole system."

### PRINCIPLE 2: MENTAL HANDLES
**Tagline:** "Give Your Brain Something to Grab"

**Scientific Foundation:**
- Principle: Complex concepts need "handles" (analogies, stories, mnemonics)
- Reference: "Poignées Mentales" — invisible tools your brain uses to grasp ideas

**Visual Metaphor:**
- **Hand grabbing a heavy object with handles** (not impossible to carry)
- OR: **Mountain climbing with ropes and handholds** — pathways to reach the summit

**Design Direction:**

**Card Layout:**
```
┌─────────────────────────────────┐
│                                 │
│   [Climber with Ropes]          │
│   Complex → Simple              │
│                                 │
│  Big Ideas Are Easier When      │
│  You Have Something to Hold On. │
│                                 │
│  ✓ Analogies That Stick         │
│  ✓ Stories That Explain         │
│  ✓ Mnemonics That Persist       │
│                                 │
└─────────────────────────────────┘
```

**Visual Elements:**
- **Illustration:** Climber on mountain with rope, glowing handholds leading upward, summit in distance
- **Colors:** Terracotta (#C75B39) + Gold (#D4AF37) rope/handles
- **Style:** Warm, encouraging, upward momentum
- **Icons:** Rope coil, mountain peak, hand reaching
- **Metaphor depth:** Handles = the specific analogies NKOM generates, mountain = challenging concepts

**Use Cases:**
- Homepage feature section
- In-app feature explanation
- TikTok explainer (short form)
- Email marketing

**Copy That Works With This Visual:**
> "Photosynthesis isn't about memorizing equations. It's about understanding that plants are solar panels. That's a mental handle—and NKOM gives you one for every concept."

- OR: **Fire emoji + smile** (engagement + joy)

**Design Direction:**

**Card Layout:**
```
┌─────────────────────────────────┐

│      XP • Streaks • Levels      │

│  ✓ Challenges & Rewards         │
│  ✓ Feel Accomplished            │
│                                 │
```

**Visual Elements:**

**Use Cases:**
- Website feature deep-dive

- Instagram carousel (room-by-room walkthrough)

**Copy That Works With This Visual:**

## DESIGN CHECKLIST FOR CREATOR/DESIGNER

When designing each principle asset, ensure:

- [ ] **Represents the principle accurately** (not just pretty)
- [ ] **Works at multiple sizes** (social media, print, in-app)
- [ ] **Accessible colors** (WCAG AA contrast minimum)
- [ ] **Inclusive imagery** (diverse faces, genders, abilities)
- [ ] **African aesthetic integrated** (not just Western design)
- [ ] **Scientific credibility** (references visible research)
- [ ] **Emotional resonance** (inspires, doesn't lecture)
- [ ] **Brand consistency** (uses NKOM color palette)
- [ ] **Minimalist** (removes non-essentials)
- [ ] **Memorable** (people want to share)
